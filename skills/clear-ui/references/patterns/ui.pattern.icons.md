# ui.pattern.icons · 图标与对象标识

- 类型：条件模式
- 状态：试用；按场景选择

## 适用

需要区分对象类型、表达熟悉动作或增强状态识别。

## 做法

图标选择固定语义、统一笔画和尺寸。暂停、启用、离线等常见状态优先用图标；保持可访问名称，悬停与键盘聚焦可提供解释。只有状态陌生、过多或需要说明原因时再加可见文字。对象标识可用小型底板形成识别锚点；陌生操作搭配文字，熟悉图标仍有可访问名称及必要提示。

## 反例与取舍

随机给句子配图；每条汇报使用虚构人物头像；不同动作共用同一图标；仅靠图标表达关键异常原因。

## 验证

不读全文也能区分对象与操作类型，键盘/读屏能识别功能；去掉装饰性图标不会损失真实信息。
