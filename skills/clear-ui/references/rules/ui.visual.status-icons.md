# ui.visual.status-icons · 常见状态图标优先

- 类型：规则（在适用场景中检查）
- 状态：试用；用户于2026-11-17明确要求

## 适用

界面以标记展示暂停、启用、离线等状态，而非解释具体原因的正文。

## 正向要求

常见状态优先使用固定语义的图标，保证可访问名称与解释途径；支持悬停提示，独立可聚焦的标记支持键盘提示。图标含义陌生、状态过多难区分或需要解释原因时，补充必要文字。形状也能区分状态，不仅依赖颜色。

## 禁止

所有状态默认堆重复文字；只留无名称的图形；为了省文字把不同状态画成同一图标；把此规则扩大到删除对象名称、分类名称或异常原因。

## 验证

核对图标与真实状态一致，悬停/聚焦可解释，读屏有名称；使用陌生或复杂状态检查文字例外。不能凭设计者熟悉图标就认定所有用户都能理解。
