# ui.behavior.states · 状态真实且可区分

- 类型：规则（在适用场景中检查）
- 状态：试用；依据真实任务持续复核

## 适用

对象存在启用、暂停、忙碌、离线、未知等不同状态。

## 正向要求

区分期望状态、观测状态和数据新鲜度；缺少证据时显示“未知”，不把未收到汇报等同失败。正常暂停使用中性色，异常再强调。

## 禁止

绿色圆点表示“启用”却被理解为“正在工作”；加载时显示零；仅用颜色区分状态。

## 验证

对照源数据核对状态与时间；读者能区分“未启用”“离线”“正在执行”和“不知道”。

状态表现另见 [ui.visual.status-icons](ui.visual.status-icons.md)。
