# 布局与导航

- `ui.clarity.region-purpose`：每区有明确用途。主内容占主要面积，动作靠近对象。
- `ui.clarity.relationships`：归属用缩进或连线，同类字段对齐；密度高时用表面或边界补充分组。
- `ui.clarity.stable-locations`：相同功能位置和术语一致，切换与返回保留选择、筛选和合理阅读位置。
- `ui.clarity.total-effort`：沿完整任务衡量寻找、操作与恢复成本，高频路径保留直接入口。
- `ui.clarity.useful-space`：限制侧栏宽度与正文行长，优先删除重复标题并保留可读字号。
- `ui.behavior.responsive-context`：窄屏突出当前任务与返回入口，隐藏内容退出焦点序列；视口改变时保留选择。
- `ui.pattern.spacing`：组内间距小于组间间距，沿稳定对齐线扫描；容器内边距说明内容归属。
- `ui.pattern.list-detail`：宽屏保留列表与详情，窄屏切换成独立列表和详情。
- `ui.pattern.list-table`：顺序浏览用列表，列间比较用带表头的表格；有批量任务才加选择。
- `ui.pattern.supporting-pane`：辅助信息可收起并保留主区可读宽度；窄屏按需转独立页或临时面板。
- `ui.pattern.navigation-tabs`：全局去处用侧栏，同一对象的并列视角用页签；可分享和返回的状态写入 URL。
- `ui.pattern.tree`：树用于定位，图用于理解分布；层级含义稳定，只画有业务含义的连接。
