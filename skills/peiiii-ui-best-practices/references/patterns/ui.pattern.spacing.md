# ui.pattern.spacing · 空间、邻近与对齐

- 类型：条件模式
- 状态：试用；按场景选择

## 适用

需要组织一组控件、对象集合、正文或页面区域。

## 做法

建立少量可复用间距；组内小、组间大，沿固定对齐线扫描。容器内边距解释内容归属；正文留合适行长。间距不足以分组时使用背景或边界。

## 反例与取舍

平均分配全部空隙；用无限放大间距弥补组织缺失；为了塞下内容不断缩字号；把空白越多当作越高级。

## 验证

换成长名称、缺字段及长正文，分组仍成立；首屏能读到主信息，缩小视口不会丢控件。

容器内容与交互背景边界的距离，按共享规则[ui.layout.content-inset](https://github.com/Peiiii/ui-rules/blob/main/rules/layout/content-inset.md)检查；正文由UI Rules唯一维护。
