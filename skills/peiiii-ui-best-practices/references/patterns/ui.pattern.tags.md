# ui.pattern.tags · 标签与状态标记

- 类型：条件模式
- 状态：试用；按场景选择

## 适用

需要快速识别类型、状态或优先级，而非阅读一整句说明。

## 做法

用短标签表达一个明确维度；中性色表示普通分类/暂停等状态，强调色表示具有依据的活跃/异常等语义。常见状态默认优先用图标及可访问名称；图标不足以区分时再配短文字。分类标签按内容保留文字，不把状态图标优先扩大为“所有文字都删掉”。筛选chip具有选中和可操作反馈。

## 反例与取舍

每个字段都贴标签；颜色没有固定含义；把已启用写成运行成功；把普通状态标记做成似乎可点击的按钮。

## 验证

多种状态混排时能扫描，灰度下仍理解含义；标签布局不挤压名称；只有真的可操作时才表现交互。
