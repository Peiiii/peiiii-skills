# ui.behavior.action-focus · 操作按钮禁止多层或悬空的焦点外圈

- 类型：硬性规则，每次实现、改动或评审操作按钮时必查
- 优先级：发布前阻断项

## 适用

所有操作按钮，尤其是紧凑图标、更多菜单、弹窗触发与关闭按钮，以及点击区域大于可见图标底色的触控控件。

## 正向要求

- 基础 Button 与 IconButton 统一拥有焦点样式。键盘聚焦显示清晰、贴合可见控件的一层标记。优先用内收的描边；当点击区域比可见控件大时，标记沿可见表面绘制。
- 指针点击和触屏操作结束后恢复普通视觉态。保留菜单和对话框的焦点归还。若原语恢复焦点时浏览器仍匹配 `:focus-visible`，而实测出现误显示，在共享基础层记录最后一次输入方式并修正焦点提示的显示条件，不改变焦点移动。
- 覆盖主题、高对比度、键盘焦点及按下、菜单打开、选中等状态。各状态可辨认，焦点边界不得挤压布局。

## 禁止

- 将页面级 `outline`、浏览器默认环和组件 `ring` 或 `box-shadow` 叠到同一个按钮。禁止外扩的圆环、空隙和双重轮廓，尤其禁止紧凑图标上围绕整个触控区画一圈。
- 用 `:focus` 或菜单打开态直接绘制键盘焦点环。禁止全局去掉键盘焦点、调用 `blur()` 隐藏外圈、阻止必要的自动焦点归还。

## 验证

1. 指针移入、按下、打开菜单、点击外部关闭、移开。检查任一步都没有残留的焦点外圈。
2. 用 Tab 聚焦，Enter 打开，Escape 退出。确认焦点回到触发器，仍只有一层清楚的贴合标记；继续 Tab 可以离开。
3. 在一个暗色主题或强制色彩模式复查可见性，在窄屏检查标记没有沿 44px 命中区域外扩。复现问题时检查 computed style 的 `outline`、`outline-offset`、`box-shadow` 和伪元素，定位是谁画了每一圈。
