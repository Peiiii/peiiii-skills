# ui.visual.surface-restraint · 视觉强调应有明确用途

- 类型：规则（在适用场景中检查）
- 状态：试用；依据真实任务持续复核

## 适用

正在增加或删除边框、背景、阴影、颜色、标签或图标。

## 正向要求

每种视觉手段用于解释归属、层级、状态或操作。区分不足时补足线索，区分足够时停止叠加；使用主题语义变量并保持跨状态一致。

## 禁止

所有区域同时加边框、阴影和亮色；把所有表面抹成同色以追求干净；把阴影当通用高级感；用彩色标签伪造业务结果。

## 验证

说明每种强调服务的判断，删除无用途的强调后结构仍成立；浅色、深色及关键选中态都能辨认，没有靠装饰掩盖的信息缺口。
