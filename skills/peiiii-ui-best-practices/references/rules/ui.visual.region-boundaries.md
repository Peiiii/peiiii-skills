# ui.visual.region-boundaries · 密集内容必须有可辨认分区

- 类型：规则（在适用场景中检查）
- 状态：试用；依据真实任务持续复核

## 适用

同屏存在多个对象、工具和内容块，依靠读字才能分辨归属时。

## 正向要求

让主要功能区及重复对象有可感知的分组。选择背景、容器边界、间距、对齐或排版差异中足够有效的一种或组合；明确组内比组间更紧密。

## 禁止

删除容器后把大量同样式文字平铺；认为有留白就一定有分区；仅在悬停时才显示对象边界。已经充分区分的区域不必再叠加装饰。

## 验证

用真实密集内容看默认态，指出各块的范围及归属；遮住部分文字仍能识别功能分区。看不出边界即为finding，不用“极简风格”豁免。
