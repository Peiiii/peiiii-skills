# ui.behavior.accessibility · 可访问性是清晰度的底线

- 类型：规则（在适用场景中检查）
- 状态：试用；依据真实任务持续复核

## 适用

所有可交互界面，尤其自定义控件与图标按钮。

## 正向要求

复用语义组件；键盘焦点可见，图标按钮有名称，状态不只靠颜色。普通文字目标对比度至少4.5:1，大字3:1；可点击目标按WCAG2.2适用条件至少24×24 CSS像素或满足间距等例外。

## 禁止

以灰色小字创造“高级感”；只能悬停看到关键信息；假按钮；只跑自动扫描就宣称全部无障碍通过。

## 验证

键盘走核心路径并检查放大、焦点和长文本；自动检查与人工观察分别报告，参考WCAG适用条件。
